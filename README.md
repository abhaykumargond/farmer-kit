# Farmer‑Kit — Web3 Food Traceability System

A **Blockchain-based** and **Web3-enabled** food traceability platform designed to ensure **transparency, security, and trust** throughout the agricultural supply chain. Farmer‑Kit bridges the gap between farmers and consumers using decentralized, tamper-proof data storage.

---

## 🚀 Live Demo  
Explore the deployed application here: [farmer‑kit.vercel.app](https://farmer-kit.vercel.app)

---

## ✨ Key Features

- **Traceability:** Track food products across each stage—farming, processing, distribution, retail.  
- **Immutable Records:** Leverage blockchain for tamper-resistant logging of trace data.  
- **Web3 Integration:** Authenticate users via Web3 wallets and interact with smart contracts.  
- **Responsive Frontend:** Built with React, HTML, CSS, and JavaScript for seamless user experience.  
- **Robust Backend:** Powered by Java, PHP, and MySQL for reliable data handling and API services.  
- **End-to-End Solution:** Blends decentralized blockchain nodes with traditional server-side architecture.

## ⚙️ Installation & Setup

### 1. Clone the Repo
```bash
git clone https://github.com/abhaykumargond/farmer-kit.git
cd farmer-kit
```

### 2. Set up Frontend
```bash
cd public
npm install
npm run dev
```

### 3. Blockchain & Backend Setup
- Deploy smart contracts to a testnet (e.g., Ethereum, BSC testnet).  
- Configure Web3 provider (e.g., MetaMask).  
- Initialize Java/PHP backend and link to your MySQL database.  
- Update environment variables (RPC endpoint, database credentials, API ports).  

---

## 🔄 Workflow Overview

1. **Connect Wallet:** Users authenticate using Web3-compatible wallets (e.g., MetaMask).  
2. **Record Data:** Farmers or supply chain actors log product lifecycle events to the blockchain.  
3. **View Traceability:** Consumers can trace the full history of products with verifiable data.  
4. **Secure & Transparent:** All actions are immutable and recorded securely with blockchain integrity.
